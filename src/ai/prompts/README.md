# AI Prompts

This directory contains prompt templates.

## Prompt Categories

### Academic Prompts
- Essay evaluation
- Grading rubrics
- Feedback generation

### CBT Prompts
- Cognitive exercises
- Reflection guidance
- Progress tracking

### Engineering Prompts
- Code review
- Documentation generation
- Technical explanations

## Guidelines

All prompts should:
- Be tenant-aware
- Support variable substitution
- Include context markers
- Have version tracking
